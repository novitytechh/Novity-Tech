# Novity Tech — Digital Excellence & Engineering

Modern, high-performance Next.js web application engineered for **Novity Tech**.

Live Preview: [https://hexteltech.vercel.app/](https://hexteltech.vercel.app/)  
GitHub Repository: [https://github.com/novitytechh/Novity-Tech](https://github.com/novitytechh/Novity-Tech)

---

## 🚀 Key Features & Extracted Modules

- **Next.js 14 App Router**: Fast, responsive, server-side rendered and static pre-rendered routes.
- **Client Reviews & Testimonials (`/reviews`)**:
  - Filterable by Web Platforms, Cloud Architecture, AI Agents, and Design Systems.
  - Transparent performance metrics (+320% Traffic, 2.4x Revenue, 99.99% Uptime SLA).
  - Collaboration commitment pillars (100% Code & IP Ownership, Direct Founder Access).
- **Cookie Consent & Governance (`/cookie-policy`)**:
  - Floating cookie banner with granular consent customization (Essential, Analytics, Marketing).
  - Comprehensive cookie categorization table and GDPR compliance.
  - Dynamic cookie settings reopen trigger.
- **Custom Futuristic 404 Page (`/_not-found`)**:
  - Coordinates unresolved system display.
  - Integrated search bar and quick navigation shortcuts.
- **Privacy Policy (`/privacy-policy`)**:
  - Enterprise data governance, NDA security controls, and client confidentiality.
- **Interactive Agency UI**:
  - Light / Dark Mode live theme toggle.
  - Custom lerping animated cursor with element scaling.
  - Pricing switch with 20% annual discount calculations.
  - Interactive portfolio filter & detailed case study popups.
  - Interactive service modals.
  - Real-time contact form with submit status feedback.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Library**: React 18
- **Styling**: Bootstrap 5 + Custom CSS Variable System (Responsive, Light/Dark theme)
- **Icons**: FontAwesome 6.5
- **Animations**: CSS Keyframes + Smooth Lerp Custom Cursor + Pure React Modals

## 💻 Getting Started

```bash
# Clone the repository
git clone https://github.com/novitytechh/Novity-Tech.git

# Navigate into the project
cd Novity-Tech

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build

```bash
npm run build
npm start
```
